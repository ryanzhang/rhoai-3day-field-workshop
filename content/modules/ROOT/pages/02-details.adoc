* 一个专用的 OpenShift {ocp_version} 集群，已安装 OpenShift AI {rhoai_version}，含一个带 NVIDIA L4 的 GPU 节点，以及由 OpenShift GitOps 安装的工作坊所需 Operator。
* 你的用户，在本集群中具有集群管理员权限。

== 登录

. 打开 OpenShift 控制台：
  link:https://console-openshift-console.{cluster_domain}[console-openshift-console.{cluster_domain}^]。
. 选择培训师指定的身份提供商（在测试集群上为 *keycloak*），使用你的用户名和密码登录。
. 检查右上角的用户菜单。

预期结果：控制台在*概览*页面打开，左侧导航顶部显示*核心平台*，右上角用户菜单显示你的名字，例如 `Kuro Admin`。

命令行前置检查是 xref:03-module-01-your-cluster.adoc[模块 1] 的第一个练习，在 Web Terminal 中运行。

== 练习之间的依赖关系

请在同一个 Web Terminal 会话中，从头到尾依次运行每个模块。后续练习会使用同一模块中前面练习定义的 Shell 变量和辅助函数（例如模块 3 中的注册表 URL，或模块 9 中的 `check` 辅助函数），以及保存在终端主目录中的文件（集群 CA 证书保存在 `~/ingress-ca.crt`，MaaS 密钥保存在 `~/key-gold` 和 `~/key-bronze`）。

如果 Web Terminal 重启（一段时间不活动后会自动停止，关闭浏览器标签也可能终止会话），请从当前模块的第一个练习重新运行所有代码块。每个代码块都可以安全地重复运行；对于前面练习中故意破坏后修复的情况（模块 5 的 Authorino TLS，模块 9 的评判器），重新运行后会显示修复后的状态，而不是故障状态。第三天开始时会检查你的 MaaS 密钥，如果密钥已丢失则重新生成一个。

== 为什么本指南中没有终端

你正在阅读的 Showroom 页面不需要登录。嵌入其中的终端会以部署它的人的权限运行，并且任何知道 URL 的人都可以访问。由于你的用户是集群管理员，因此请在控制台的 Web Terminal 中操作，它会在你登录后以你的身份运行。
